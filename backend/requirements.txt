# needs, and the ceilings stop a major release from silently breaking it.
#
# Exact pins would be more reproducible but they hard-fail on newer Python.
# pydantic 2.10 resolves pydantic-core 2.27, which ships no cp314 wheel, so on
# Python 3.14 pip falls back to a Rust source build that fails on a stock
# machine. Ranges let pip pick a build that exists for the interpreter in use.
